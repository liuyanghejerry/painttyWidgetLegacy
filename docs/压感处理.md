# 平滑绘图算法实现文档

## 概述

本文档详细介绍了一个支持压感和倾角的高级绘图算法，该算法能够产生类似书法的自然笔触效果，具有平滑的线条和优雅的起收笔效果。

## 核心特性

### 1. 压感支持 (Pressure Sensitivity)
- 支持 Pointer Events API 获取压感数据
- 压感范围：0.0 - 1.0
- 实时显示当前压感值
- 支持鼠标、触摸屏、手写笔等多种输入设备

### 2. 倾角支持 (Tilt Support)
- 支持 X 轴和 Y 轴倾角检测
- 倾角范围：-90° 到 +90°
- 倾角影响线条形状和粗细
- 模拟真实画笔的倾斜效果

### 3. 书法风格渲染
- 自然的起笔和收笔效果
- 流畅的粗细变化
- 无锯齿的平滑线条
- 类似毛笔的视觉效果

### 核心绘制算法

#### 1. 压感数据预处理

```typescript
// 三点加权平均平滑处理
const smoothedPoints = points.map((point, index) => {
  let smoothedPressure = point.pressure || 0.5

  if (index > 0 && index < points.length - 1) {
    const prevPressure = points[index - 1].pressure || 0.5
    const nextPressure = points[index + 1].pressure || 0.5
    // 加权平均：前25% + 当前50% + 后25%
    smoothedPressure = prevPressure * 0.25 + point.pressure * 0.5 + nextPressure * 0.25
  }

  return { ...point, pressure: smoothedPressure }
})
```

#### 2. 书法起收笔效果

```typescript
// 起始点渐入效果
if (index < 3) {
  pressureMultiplier = (index + 1) / 4  // 0.25, 0.5, 0.75, 1.0
}
// 结束点渐出效果
else if (index > totalPoints - 4) {
  pressureMultiplier = (totalPoints - index) / 4  // 1.0, 0.75, 0.5, 0.25
}

smoothedPressure = Math.max(0.05, Math.min(1, smoothedPressure * pressureMultiplier))
```

#### 3. 非线性压感映射

```typescript
// 使用幂函数让压感变化更自然
const pressureCurve = Math.pow(point.pressure, 0.7)
const width = baseSize * pressureCurve * tiltMultiplier
```

#### 4. 倾角效果计算

```typescript
// 计算倾角对线条的影响
const tiltEffect = Math.abs(point.tiltX) + Math.abs(point.tiltY)
const tiltMultiplier = 1 + (tiltEffect / 180) * 0.4  // 最大40%的影响
```

#### 5. 变宽度路径生成

```typescript
// 计算垂直于线条方向的向量
const angle = Math.atan2(point.y - prevPoint.y, point.x - prevPoint.x)
const perpX = (-Math.sin(angle) * width) / 2
const perpY = (Math.cos(angle) * width) / 2

// 生成上下边缘点
const topPath = { x: point.x + perpX, y: point.y + perpY }
const bottomPath = { x: point.x - perpX, y: point.y - perpY }
```

#### 6. 贝塞尔曲线平滑

```typescript
// 使用二次贝塞尔曲线连接路径点
const cpX = (prevPoint.x + currentPoint.x) / 2
const cpY = (prevPoint.y + currentPoint.y) / 2
ctx.quadraticCurveTo(prevPoint.x, prevPoint.y, cpX, cpY)
```

## 渲染流程

### 1. 事件处理
1. **pointerdown**: 开始新的绘制路径
2. **pointermove**: 添加新的路径点，应用压感平滑
3. **pointerup**: 完成路径绘制

### 2. 实时绘制
1. 收集输入点数据
2. 应用压感和倾角平滑算法
3. 生成变宽度路径
4. 使用贝塞尔曲线渲染

### 3. 最终渲染
1. 清空画布
2. 重绘所有已完成的路径
3. 绘制当前正在进行的路径

### 事件处理

在`tabletEvent`中集成了新的压感处理系统：

```cpp
void Canvas::tabletEvent(QTabletEvent *event)
{
    switch(event->type()) {
    case QEvent::TabletPress:
        // 开始绘制路径
        startDrawingPath(event->position(), event->pressure(),
                        event->xTilt(), event->yTilt(),
                        event->rotation(), event->tangentialPressure());
        break;
        
    case QEvent::TabletMove:
        // 添加路径点
        addPointToPath(event->position(), event->pressure(),
                      event->xTilt(), event->yTilt(),
                      event->rotation(), event->tangentialPressure());
        break;
        
    case QEvent::TabletRelease:
        // 完成绘制路径
        finishDrawingPath();
        break;
    }
}
```
