Mr.Paint for macOS

Requires macOS 11 or later. This universal application includes native Apple
Silicon (arm64) and Intel (x86_64) code and its Qt runtime; Qt installation is
not required. Extract the ZIP, drag MrPaint.app to Applications, then open it.

This build has an ad-hoc integrity signature, but no Apple Developer ID
signature or notarization. On the first launch macOS may block the app. After
verifying that you downloaded it from the project's GitHub Release, open
System Settings > Privacy & Security > Open Anyway and confirm Open.
Apple's instructions: https://support.apple.com/en-us/102445

Source and updates: https://github.com/liuyanghejerry/painttyWidgetLegacy
Licenses and source commit information are inside
MrPaint.app/Contents/Resources/licenses and build-info.json respectively.
