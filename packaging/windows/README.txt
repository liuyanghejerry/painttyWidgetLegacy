Mr.Paint - offline painting for Windows x64

Extract the entire ZIP into a folder and run MrPaint.exe.
Keep the DLLs, qt.conf and plugin folders beside the executable.
Qt and the MinGW runtime are included; no Qt SDK installation is needed.

Save editable projects as .paintty files. Export images as PNG or PSD.
Preferences are stored in the Windows user's application configuration folder.

build-info.json records the package version, source commit and toolchain.
Source: https://github.com/liuyanghejerry/painttyWidgetLegacy
License texts are included in licenses/.
